# Data inventory

`datasets.tsv` records each source dataset by stable accession and version together with its analysis role, inclusion/exclusion boundary and known limitations.

`${RESEARCH_DATA_ROOT}` is a logical placeholder. Set it to the local reusable-data warehouse before running the pipeline:

```bash
export RESEARCH_DATA_ROOT=/path/to/ResearchDataHub
```

No raw source data are redistributed in this repository. Users must obtain source files from the originating repositories and comply with their access and license terms.
