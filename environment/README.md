# Reference environment

`r_packages.tsv` lists packages referenced by the released R scripts and the versions available in the reference execution environment.

`system_tools.tsv` lists external command-line tools used by acquisition, interval-processing and amplicon workflows. Tool paths are configurable through environment variables; machine-specific paths are not embedded in the release.

Package availability alone does not replace data-version, sample-identity or manifest checks implemented by the scripts.
